# 卷二：盲派命理四层断命模型与十神现代心理学精粹

> **为什么子平格局派必须配盲派？**
> 传统子平重“寒暖调候、旺衰平衡与富贵层次”，而**盲派命理（夏仲奇、郝金阳一脉）**专攻**“铁口直断具体人事（哪年结婚、哪年破财、钱从哪来、被谁分走、墓库何时冲开）”**。两者合璧，既有学院派的宏大视野，又有让用户起鸡皮疙瘩的“神准验前事”能力！

## 一、盲派断命终极四层闭环（寻根基 → 找出处 → 定份额 → 论做功）

### 第一层：寻根基（分清虚实真假，看人生底盘稳不稳）
1. **日主根基（禄、刃、库、余气）**：
   - 日主在地支有**禄神（同五行同阴阳，如甲见寅、乙见卯、丙戊见巳、丁己见午、庚见申、辛见酉、壬见亥、癸见子）**或**羊刃（帝旺根）**，代表此人底气足、抗造、能独立扛事担大财。
   - 日主地支无根虚浮（又不成从格），代表内心极度缺乏安全感、容易随波逐流、赚到钱也守不住。
2. **十神真假虚实**：
   - **透干为虚（表象/名声），通根为实（实利/里子）**。
   - 比如天干透出正偏财，但地支一点财根/食伤根都没有，叫**“虚透之财（表面风光，别人以为你很有钱，或者你自己很会聊搞钱、口才极好，但银行卡里全是空的）”**。
   - 反之，财官深藏地支本气或财库之中不露，叫**“闷声发大财（外人不显山露水，实际名下有硬核资产与存款）”**。

### 第二层：分宾主与宫位定象（一眼看穿资源归属）
1. **宾主二元铁律**：
   - **主位（我与我的家庭核心）**：**日柱（日干=我，日支=配偶宫/我的小金库） + 时柱（门户/我的晚年/我的子女/我最终落袋的资产）**。
   - **宾位（外人、父母祖上、原生家庭、社会大环境、别人的钱）**：**年柱（远方、长辈、大势） + 月柱（原生家庭、同辈同行、职场单位）**。
2. **核心断语**：
   - **“宾位之财官，通过合、制、入库连到主位”** → 拿别人的钱、赚天下人的钱落进自己口袋（大富创业/投资命）！
   - **“主位之财星，被年月的比劫合走、冲走”** → 自己的血汗钱、甚至伴侣，总被原生家庭、狐朋狗友、烂合伙人分走消耗（典型“冤大头/扶弟魔/合伙必亏”局）！

### 第三层：定份额（为什么同样见财，有人身价过亿，有人终身漏财？）
- 当命局中的财星同时连接了多个宫位时，看谁离财最近、谁根气最强：
  - **比劫争财（年月比劫紧贴财星）**：切忌与人合伙平分股份、切忌借钱给熟人！钱一露白就会有同辈朋友或突发窟窿来分钱。破局法：**主动买房置产（把流动现金变成印星不动产）**，或者做**分润机制清晰的平台分销（主动把钱分给渠道，应掉比劫夺财之象）**。
  - **印星耗财/护身**：为房产、长辈医疗、进修学习花钱。
  - **官杀泄财**：为体面、名声、职场打点、税务法务或伴侣（女命官杀为夫星）持续买单。

### 第四层：论做功与四墓库（辰、戌、丑、未）开闭秘法
1. **什么是“做功”？**
   - 八字不是越平衡越好！太平衡的八字往往安于现状、平庸一生。真正发大财的八字，都是用自己的**“体（日主、印星、比劫、食伤）”**去强力制服或合取外部的**“用（财星、官杀）”**！
   - **制用做功**：食伤制杀（靠专业技术解决高难度问题）、比劫制财（靠团队/体力/执行力强行收割市场）。
   - **合用做功**：日干合财（甲己合、乙庚合、丙辛合、丁壬合、戊癸合）、日支六合财官——精准锁定目标客户与稳定正缘，事半功倍。
   - **化用做功**：杀印相生、官印相生——把外界给你的巨大压力、危机和折磨，全部内化成你的资历、权柄与护城河！
2. **盲派绝学：四墓库（辰水库、戌火库、丑金库、未木库）铁律**：
   - **“富贵造，全靠墓库开了窍！”** 墓库装的是成批量的巨额能量（大财、大权）。
   - **区分“库”与“墓”**：某五行在原局有强根有气而入辰戌丑未，叫**“库（银行保险柜，随时等钥匙冲开暴富）”**；若某五行在原局极弱无气而入辰戌丑未，叫**“墓（坟墓/医院/死局，代表该十神所主之事或六亲压抑、病弱或缘薄）”**。
   - **“闭库待冲，逢冲大发”**：原局有财库/官库但未开，一旦走到**相冲大运或流年（辰戌冲、丑未冲、丑戌未三刑）**，墓门轰然打开，往往在短短一两年内实现阶层跃迁、买房暴富或创业爆发！
