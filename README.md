# tianji-metaphysics-skill (天机 · 学院派新中式命理宗师 Agent Skill v2.0)

一套遵循 [Agent Skills 标准](https://agentskills.io/specification)（兼容 OpenTag / Pi / Claude Code / Cursor）的**新中式命理宗师（天机）全栈 Skill 包**。

## 核心特性

1. **人设灵魂与女性主义护短底色 (`SKILL.md` & `references/00_XUANXUE_MASTER_BRAIN.md`)**
   - 锚定 35 岁上下「人间清醒 · 学院派新中式命理师」，平视称呼女性为「姐妹」、男性为「兄弟」，彻底摒弃男权命理糟粕。
   - 零 AI 痕迹纯文本排版（严禁 `**` 等 Markdown 符号），专业术语首次出现强制附带中文括号 `（）` 大白话翻译。
   - 内置固定破冰开场白、「一事一断 vs 开盘前三刀」动态去重路由、每日早 8:00「穿搭颜色外应 / 昨晚梦境流日解象」单双日交替问候机制。

2. **v2.0 铁口排盘与双人合盘引擎 (`engine/xuanxue_engine.py`)**
   - **子平八字 + 盲派做功 + 穷通宝鉴调候 (`bazi`)**：内置中国 300+ 地级/县级市经度库与均时差（Equation of Time）真太阳时校准、天干五合、地支六冲/六合/三合/六害/三刑、四墓库开闭与大运流年交互雷达。
   - **紫微斗数全盘 v2.0 (`ziwei`)**：十四主星 + 六吉星（左辅/右弼/文昌/文曲/天魁/天钺）+ 六煞星（擎羊/陀罗/火星/铃星/地空/地劫）+ 禄存/天马/红鸾/天喜桃花星 + 生年四化 + 十二宫十年大限年龄区间。
   - **双人八字深度合盘 (`hepan`)**：支持有/无具体出生时辰（`--no-time2`），自动扫描宿命干支同柱、天地鸳鸯合、夫妻宫（日支）冲合害、五行调候互补链与桃花密度边界预警。
   - **梅花易数 & 小六壬 (`meihua` & `xiaoliuren`)**：报 3 个数字秒起本卦/互卦/变卦体用生克与小六壬三宫演进。

3. **六卷命理核心典籍 (`references/01~06_*.md`)**
   - 卷一：子平八字与真太阳时精要
   - 卷二：盲派做功与十神心性断法
   - 卷三：周易六十四卦、梅花易数与六爻断法
   - 卷四：小六壬马前课与紫微斗数飞星精要
   - 卷五：正缘骨相身材外貌画像、双人合盘四层雷达与 2026-2027 精确到流月应期表
   - 卷六：学院派「主动应象」改命与五行调候生活处方（买小克重金豆化比劫夺财、洗牙献血化羊刃逢冲等）

4. **微信多用户 ClawBot (iLink) 调度架构 (`wechat-clawbot/`)**
   - 包含 `ilink_common.py`、`onboard.py`、`poller.py`、`send_image.py`（已 100% 脱敏，不含任何用户档案与私密 token）。
   - 支持微信对话内输入 `发码 <称呼>` 秒回纯净邀请二维码、后台非阻塞自动建档、主 Session v2.0 排盘预计算注入与早 8:00 交替晨间问候。
